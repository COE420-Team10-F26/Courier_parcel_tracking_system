# Courier Parcel Tracking System

COE420L Software Engineering, Fall 2026, Team 10, American University of Sharjah.

A system that lets customers book and track parcels, admins assign parcels to field staff by zone, and field staff update delivery status with proof of delivery, with automatic notifications and delay alerts.
