# Project Scope

Project Objective: Build a system where customers can book a parcel for delivery and track its status as it moves through pickup and delivery, while field staff update that status and admins manage the overall operation. The point is replacing manual, untracked handoffs with something transparent both sides can actually see.

Target Users: Customers, meaning both senders and recipients. Field staff who handle pickup and delivery. Administrators who manage accounts and oversee the system.

In-Scope Features:
- User registration and role based login for customers, field staff, and admins
- Parcel booking with sender, recipient, and parcel details
- Auto generated tracking numbers
- Status updates whenever field staff change a parcel's delivery stage
- Pickup, shipment, and delivery assignment management
- Delivery confirmation and proof of delivery
- Notifications when parcel status changes
- Admin dashboard for monitoring users and parcels

Out-of-Scope Features:
- Barcode or QR code label generation
- Payment and shipping cost calculation
- Complaint and dispute handling
- Reports and analytics
- Detailed workflows for damaged, returned, or cancelled parcels

Major Deliverables: A working web app covering the features listed above, the source code in the team repo, basic setup documentation, and a final demo.
